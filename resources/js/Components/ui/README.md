Shared UI components for AgriVerse.

This directory contains reusable UI components built with PrimeVue + Tailwind CSS v4.

## Components:
- UiButton.vue — Unified button component
- UiCard.vue — Card wrapper with consistent styling
- UiModal.vue — Modal/dialog component
- UiTable.vue — Data table with sorting/pagination
- UiForm.vue — Form layout helper
- UiInput.vue — Input field with validation display
- UiBadge.vue — Status badge component
- UiToast.vue — Toast notification wrapper

Usage: import { UiButton } from '@/Components/ui'

Note: These components supplement PrimeVue's built-in components.
Use PrimeVue components (pv-*) for complex UI and these for shared patterns.

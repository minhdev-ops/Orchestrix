# AgriVerse Hub: UI/UX Design & Prototype

## 1. Design Philosophy: Agri-Tech Minimalism
- **Colors:** Neutral tones (White, Light Grey #F5F5F5) + Primary "Forest Green" (#2D5A27).
- **Focus:** 60% of screen real estate dedicated to the 3D Viewer.
- **Typography:** Clean, sans-serif fonts (e.g., Inter, Roboto).

## 2. Information Architecture
### 2.1. Buyer Experience
- **Home:** Intelligent Search + Categories ("Agri-Aesthetics", "Agri-Machinery").
- **Product Page:** 3D Viewer, Interactive Controls, "Try AR" button (Mobile), Technical Specs (Digital Passport).
- **Checkout:** Order confirmation + E-Contract signature.

### 2.2. Seller Dashboard
- **Overview:** Sales charts & Subscription status.
- **3D Inventory:** List of models with AI processing status badges.
- **Upload Portal:** Drag-and-drop for 360 videos or raw 3D files.

## 3. Detailed UI Components
- **Agri-Aesthetics (Mobile First):**
  - Gestures: Swipe to rotate, Pinch to zoom.
  - WebAR button: Bottom-right corner, triggers floor detection.
- **Agri-Machinery (Desktop Optimized):**
  - Dark Mode/Studio Grey background.
  - "Exploded View" button: Triggers automated component separation.
  - "Play Animation" button: Shows operational flow.

## 4. Prototyping Tools
- **2D Design:** Figma.
- **3D Interactive Prototypes:** Spline or Sketchfab.
- **Development implementation:** Three.js.

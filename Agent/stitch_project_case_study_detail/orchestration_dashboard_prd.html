# PRD: Orchestration Dashboard (Hệ thống quản lý tập trung) ## 1. Overview Hệ thống điều khiển trung tâm (Orchestration Dashboard) dành cho Senior Frontend Architect. Quản lý các module độc lập (n8n, GitHub Actions, v.v.) và tương tác với các project vệ tinh. ## 2. Layout Structure * **Sidebar:** Danh mục Module (Automation, Monitoring, User Management, Database Sync) + Trạng thái Online/Offline. * **Main Dashboard Overview:** * Widget Health Status của các project liên kết. * Biểu đồ luồng dữ liệu (Data flow) giữa các project. * **Module Detail View:** * **Control Panel:** Toggles, Execute buttons (Trigger n8n, Deploy GitHub). * **Interaction Logs:** Lịch sử tương tác module-project. * **Configuration:** API Key, Webhook URL setup. * **Global Search & Command Bar:** Truy cập nhanh. ## 3. Technical & Aesthetic Requirements * **Design System:** Bento Grid hiện đại, Glassmorphism. * **Color Palette:** Dark theme (Deep Navy/Slate). * **Status Colors:** Emerald (Hoạt động), Amber (Đang xử lý), Rose (Lỗi). * **Responsive:** Desktop (Full control) & Tablet (Quick monitor). ## 4. Key UI Components * Hệ thống phân quyền (Admin/Manager/User). * API/Webhook Feedback (Hiển thị kết quả lệnh thực thi). * Trạng thái kết nối (Connected, Disconnected, Authenticating). * Sơ đồ trực quan (Mini-map/Node-based UI). * Notification Hub.

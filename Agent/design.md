# Design System: Deep Dark SaaS Aesthetic

## 1. Visual Theme & Atmosphere

The design focuses on a professional, high-fidelity IT Portfolio inspired by high-end SaaS landing pages and GitHub profiles. It uses a "Deep Dark Mode" with high contrast, minimal lines, and plenty of whitespace.

**Key Characteristics:**
- **Background**: Deep Dark (`#0d1117`)
- **Primary Accent**: GitHub Blue (`#58a6ff`)
- **Borders**: Muted Slate (`#30363d`)
- **Rounded Corners**: 8px standard
- **Effects**: Glassmorphism, subtle glowing accent borders, micro-interactions, hover lifts.

## 2. Color Palette & Roles

### Backgrounds
- **Primary BG**: `#0d1117`
- **Card BG**: `#161b22`
- **Surface Muted**: `#21262d`

### Accents & Borders
- **Primary Blue**: `#58a6ff`
- **Border Default**: `#30363d`
- **Accent Glow**: `rgba(88, 166, 255, 0.4)`
- **Tech Cyan**: `#39c5bb` (for project highlights/borders)

### Typography
- **Heading/Body**: Inter or Roboto (Professional Sans-serif)
- **Technical/Small**: Monospace font (for subtle descriptions)
- **Text Primary**: `#c9d1d9`
- **Text Muted**: `#8b949e`

## 3. Component Stylings

### Project Cards
- **Grid**: 3-column responsive layout
- **Style**: Dark grey background (`#161b22`), thin cyan border (`#39c5bb`)
- **Features**: Pill-shaped tech badges, outlined "Code" & "Demo" buttons with transitions.

### Tech Stack / Skills (Bento Tiles)
- **Layout**: Interactive Bento-box (variable tile sizes)
- **Effects**: Hover lift + brand-colored glows (Flutter: Blue, Laravel: Red, etc.)
- **Icons**: Official high-resolution tech icons.

### Navigation
- **Style**: Sticky glassmorphism bar
- **Aesthetic**: Minimalist, clean lines, high whitespace.

## 4. UI/UX Principles
- **Visual Hierarchy**: Projects are the primary focus (the "heart" of the portfolio).
- **Contrast**: High contrast for technical code/text readability.
- **Micro-interactions**: Small kinetic movements on button/card hovers.
